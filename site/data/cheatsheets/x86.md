# x86-64 assembly cheat sheet

Quick reference for Crucible's x86-64 problems: **AT&T syntax on macOS**, assembled with
Apple `clang`, System V AMD64 calling convention. Comments start with `#`. On Apple Silicon
the program runs under Rosetta 2. Every snippet here was assembled and run.

## How Crucible calls your function

The harness is C code that calls your function `_<fn>` (macOS prefixes C symbols with an
underscore). It follows the System V AMD64 calling convention:

| Crucible type | arrives in | notes |
|---|---|---|
| `int` | one 64-bit register | 64-bit signed (`long long`) |
| `int[]` | **two** registers: pointer, then count | elements are 8 bytes each; count is 64-bit |
| `str` | one register: `const char*` | NUL-terminated bytes |
| return `int` | `%rax` | |
| `void` + mutates | write through the array pointer | |

Integer parameters fill `%rdi`, `%rsi`, `%rdx`, `%rcx`, `%r8`, `%r9` in order.
`f(nums: int[], target: int)` gets `%rdi = nums`, `%rsi = count`, `%rdx = target`.

```asm
    .text
    .globl  _sum_array               # export the symbol
    .p2align 4                       # 16-byte align the function (what clang emits)
_sum_array:                          # long long sum_array(long long* rdi, long long rsi)
    xorl    %eax, %eax               # rax = 0 (running sum)
1:  testq   %rsi, %rsi               # no elements left?
    je      2f                       # jump forward to label 2
    addq    (%rdi), %rax             # sum += *p
    addq    $8, %rdi                 # p++ (8-byte elements)
    decq    %rsi
    jmp     1b                       # jump back to label 1
2:  ret                              # result is already in rax
```

Numeric labels (`1:`) can be reused; `1b` / `1f` mean "nearest label 1 backward /
forward".

## AT&T vs Intel syntax

Crucible uses **AT&T** (the default for clang/GNU tools). Most online material and the
Intel manuals use Intel syntax, so learn to translate:

| | AT&T (use this) | Intel |
|---|---|---|
| operand order | `op src, dst` | `op dst, src` |
| registers | `%rax` | `rax` |
| immediates | `$42`, `$-1`, `$0x10` | `42` |
| size | instruction suffix: `movb/w/l/q` | `BYTE/WORD/DWORD/QWORD PTR` |
| memory | `disp(base,index,scale)` | `[base + index*scale + disp]` |
| example | `movq 8(%rdi,%rcx,8), %rax` | `mov rax, [rdi + rcx*8 + 8]` |
| example | `subq $16, %rsp` | `sub rsp, 16` |
| compare | `cmpq %rsi, %rdi` (rdi vs rsi) | `cmp rdi, rsi` |
| sign-extend | `cqto`, `cltq`, `movslq`, `movsbq` | `cqo`, `cdqe`, `movsxd`, `movsx` |
| zero-extend | `movzbl`, `movzbq` | `movzx` |

`movq $5, %rax` (immediate) versus `movq 5, %rax` (load from **address 5**: crash) is the
classic AT&T typo. `.intel_syntax noprefix` switches the assembler to Intel syntax, but
don't mix styles.

## Registers

| 64-bit | 32 | 16 | 8 | role (System V) | preserved across calls? |
|---|---|---|---|---|---|
| `%rax` | `%eax` | `%ax` | `%al` | return value; implicit in `mul`/`div` | no |
| `%rdi` | `%edi` | `%di` | `%dil` | argument 1 | no |
| `%rsi` | `%esi` | `%si` | `%sil` | argument 2 | no |
| `%rdx` | `%edx` | `%dx` | `%dl` | argument 3; high half of `mul`/`div` | no |
| `%rcx` | `%ecx` | `%cx` | `%cl` | argument 4; `%cl` = variable shift count | no |
| `%r8` | `%r8d` | `%r8w` | `%r8b` | argument 5 | no |
| `%r9` | `%r9d` | `%r9w` | `%r9b` | argument 6 | no |
| `%r10`, `%r11` | `%r10d`… | | | scratch | no |
| `%rbx` | `%ebx` | `%bx` | `%bl` | callee-saved | **yes** |
| `%r12`–`%r15` | `%r12d`… | | | callee-saved | **yes** |
| `%rbp` | `%ebp` | | | frame pointer (callee-saved) | **yes** |
| `%rsp` | | | | stack pointer, 16-byte aligned at each `call` | **yes** |
| `%rip` | | | | instruction pointer; used for `sym(%rip)` addressing | n/a |

Sub-register writes behave differently:

| write to | effect on the rest of the 64-bit register |
|---|---|
| 32-bit (`%eax`, `movl`) | upper 32 bits **zeroed** |
| 16-bit (`%ax`) or 8-bit (`%al`) | other bits **unchanged** |

So `xorl %eax, %eax` zeroes all of `%rax`, but `movb (%rdi), %al` leaves junk in bits
8–63: load bytes with `movzbl` instead. `%ah`/`%bh`/`%ch`/`%dh` (bits 8–15) exist but can't
be used in the same instruction as `%sil`, `%dil`, `%r8b`, etc.

A leaf function (one that calls nothing) can use the caller-saved registers freely and
needs no stack frame at all.

## System V calling convention

- Integer/pointer args: `%rdi`, `%rsi`, `%rdx`, `%rcx`, `%r8`, `%r9`; args 7+ on the stack
  (on entry, the 7th is at `8(%rsp)`, above the return address).
- Return value in `%rax` (128-bit results in `%rdx:%rax`).
- Caller-saved (clobbered by any `call`): `%rax %rcx %rdx %rsi %rdi %r8`–`%r11`, flags.
- Callee-saved (you must restore them): `%rbx %rbp %r12`–`%r15`, and `%rsp`.
- `call` pushes 8 bytes, so on entry `%rsp` is **8 mod 16**; it must be **0 mod 16** at
  every `call` you make. `pushq %rbp` fixes it.
- Red zone: a leaf function may use the 128 bytes below `%rsp` without moving `%rsp`.
- Floats/doubles go in `%xmm0`–`%xmm7` (return in `%xmm0`); all `%xmm` are caller-saved.
- Variadic calls (`printf`): set `%al` to the number of vector registers used
  (`xorl %eax, %eax` when passing none).

## Addressing modes

General form: `disp(base, index, scale)` = `base + index*scale + disp`, with `scale` ∈
{1, 2, 4, 8} and `disp` a signed 32-bit constant. Any part may be omitted.

| syntax | address | typical use |
|---|---|---|
| `(%rdi)` | `rdi` | `*p` |
| `8(%rdi)` | `rdi + 8` | `p[1]`, struct field |
| `-8(%rbp)` | `rbp - 8` | local variable |
| `(%rdi,%rcx,8)` | `rdi + rcx*8` | `a[i]`, 8-byte elements |
| `(%rdi,%rcx)` | `rdi + rcx` | `s[i]`, bytes |
| `-8(%rdi,%rsi,8)` | `rdi + rsi*8 - 8` | `a[n-1]` |
| `msg(%rip)` | address of `msg` | data/strings (required on macOS) |

There are no pre/post-increment modes: advance pointers with `addq`/`incq`. Only **one**
operand may be memory (`movq (%rdi), (%rsi)` is invalid). `leaq` computes the address
without loading:

```asm
    leaq    (%rdi,%rsi,8), %rax      # rax = &a[i]
    leaq    (%rdi,%rdi,4), %rax      # rax = rdi * 5 (no flags touched)
    leaq    msg(%rip), %rdi          # rdi = &msg
```

## Data movement

| instruction | effect |
|---|---|
| `movq %rsi, %rax` | copy register |
| `movq $42, %rax` / `movl $42, %eax` | small immediate (`movl` is shorter, zero-extends) |
| `movabsq $0x123456789, %rax` | any 64-bit immediate into a register (clang also accepts `movq` here and converts it) |
| `movq (%rdi), %rax` / `movq %rax, (%rdi)` | load / store 8 bytes |
| `movzbl (%rdi), %eax` | load byte, zero-extend (`unsigned char`) |
| `movsbq (%rdi), %rax` | load byte, sign-extend (`signed char`) |
| `movslq (%rdi), %rax` | load 4 bytes, sign-extend (`int` → `long`) |
| `leaq 8(%rdi), %rax` | address arithmetic, no memory access |
| `xchgq %rax, %rdx` | swap |
| `cmovlq %rsi, %rax` | `if (l) rax = rsi` (after a `cmp`; no immediate source) |
| `sete %al` + `movzbl %al, %eax` | `rax = (e) ? 1 : 0` |
| `pushq %rbx` / `popq %rbx` | push / pop 8 bytes |

## Arithmetic

| instruction | effect |
|---|---|
| `addq %rsi, %rax` / `addq $4, %rax` | `rax += …` (immediates are 32-bit sign-extended) |
| `subq %rsi, %rax` | `rax -= rsi` |
| `incq %rax` / `decq %rax` | `±1` (don't change CF) |
| `negq %rax` | `rax = -rax` |
| `imulq %rsi, %rax` | `rax *= rsi` (low 64 bits; fine for signed and unsigned) |
| `imulq $10, %rdi, %rax` | `rax = rdi * 10` (three-operand form) |
| `imulq %rsi` / `mulq %rsi` | `%rdx:%rax = %rax * rsi` signed / unsigned (128-bit) |
| `cqto` + `idivq %rsi` | signed `%rdx:%rax / rsi`: quotient `%rax`, remainder `%rdx` |
| `xorl %edx, %edx` + `divq %rsi` | unsigned divide |
| `cltq` | sign-extend `%eax` into `%rax` |

Division always uses `%rdx:%rax` as a 128-bit dividend, so you must set `%rdx` first:
`cqto` (sign-extend `%rax`) for signed, zero for unsigned. Quotient truncates toward zero;
remainder has the sign of the dividend, exactly like C. `idivq` takes no immediate, and
dividing by zero (or `INT64_MIN / -1`) crashes with SIGFPE.

```asm
    .text
    .globl  _divmod
    .p2align 4
_divmod:                             # long long divmod(long long a, long long b): (a/b)*100 + a%b
    movq    %rdi, %rax               # dividend must be in rax
    cqto                             # rdx:rax = sign-extended a
    idivq   %rsi                     # rax = a / b, rdx = a % b
    imulq   $100, %rax, %rax
    addq    %rdx, %rax
    ret
```

`divmod(-7, 2)` returns `-301` (quotient −3, remainder −1). Note that `idivq` overwrote
`%rdx`, which was the 3rd argument register: copy anything you need out of `%rdx` first.

## Logic & shifts

| instruction | effect |
|---|---|
| `andq $1, %rax` | bitwise AND (sets ZF/SF, clears CF/OF) |
| `orq`, `xorq` | OR, XOR |
| `xorl %eax, %eax` | zero `%rax` (clobbers flags) |
| `notq %rax` | `~rax` (no flags) |
| `testq $1, %rdi` | flags from `rdi & 1`, result discarded (odd?) |
| `shlq $3, %rax` | shift left (×8); same as `salq` |
| `shrq $1, %rax` | logical shift right (unsigned ÷2) |
| `sarq $1, %rax` | arithmetic shift right (keeps sign; floors, unlike `idiv`) |
| `shlq %cl, %rax` | variable shift: the count **must** be in `%cl` |
| `rolq $8, %rax` / `rorq` | rotate |
| `popcntq %rdi, %rax` | count set bits |
| `lzcntq` / `tzcntq` | count leading / trailing zeros (64 for input 0) |
| `bsrq` / `bsfq` | index of highest / lowest set bit (undefined for 0) |

## Flags & condition codes

`cmpq src, dst` computes `dst − src` and sets the flags. **AT&T reverses the operands**, so
read `cmpq %rsi, %rdi; jl L` as "if `rdi < rsi` goto L". With an immediate the constant
comes first: `cmpq $10, %rax` tests `rax` against 10. `testq a, b` sets flags from `a & b`.

| suffix | meaning after `cmpq %rsi, %rdi` | flags | jump | set byte | cond. move |
|---|---|---|---|---|---|
| `e` / `z` | `rdi == rsi` | ZF = 1 | `je` | `sete` | `cmoveq` |
| `ne` / `nz` | `rdi != rsi` | ZF = 0 | `jne` | `setne` | `cmovneq` |
| `l` | `rdi < rsi` (signed) | SF ≠ OF | `jl` | `setl` | `cmovlq` |
| `le` | `rdi <= rsi` (signed) | ZF = 1 or SF ≠ OF | `jle` | `setle` | `cmovleq` |
| `g` | `rdi > rsi` (signed) | ZF = 0 and SF = OF | `jg` | `setg` | `cmovgq` |
| `ge` | `rdi >= rsi` (signed) | SF = OF | `jge` | `setge` | `cmovgeq` |
| `b` | `rdi < rsi` (unsigned) | CF = 1 | `jb` | `setb` | `cmovbq` |
| `be` | `rdi <= rsi` (unsigned) | CF = 1 or ZF = 1 | `jbe` | `setbe` | `cmovbeq` |
| `a` | `rdi > rsi` (unsigned) | CF = 0 and ZF = 0 | `ja` | `seta` | `cmovaq` |
| `ae` | `rdi >= rsi` (unsigned) | CF = 0 | `jae` | `setae` | `cmovaeq` |
| `s` / `ns` | result negative / non-negative | SF = 1 / 0 | `js` / `jns` | `sets` | `cmovsq` |
| `o` / `no` | signed overflow / none | OF = 1 / 0 | `jo` / `jno` | `seto` | `cmovoq` |

Signed: `l g le ge` (less/greater). Unsigned: `b a be ae` (below/above): use these for
pointer comparisons and sizes.

What sets flags: `cmp`, `test`, `add`, `sub`, `and`, `or`, `xor`, `neg`, shifts, `inc`/`dec`
(not CF). What doesn't: `mov`, `lea`, `push`, `pop`, `not`, `jmp`, `call`, `setcc`,
`cmovcc`. Anything between the `cmp` and the `jcc` must not set flags.

## Control-flow patterns

`if (a < b) x = 1; else x = 2;` (a in `%rdi`, b in `%rsi`): jump on the **opposite**
condition to the else branch.

```asm
    cmpq    %rsi, %rdi               # compare a with b
    jge     1f                       # !(a < b) -> else
    movl    $1, %eax                 # then
    jmp     2f
1:  movl    $2, %eax                 # else
2:
```

Branch-free versions:

| C | x86-64 |
|---|---|
| `x = (a == b)` | `xorl %eax, %eax` / `cmpq %rsi, %rdi` / `sete %al` |
| `x = a < b ? a : b` | `movq %rdi, %rax` / `cmpq %rdi, %rsi` / `cmovlq %rsi, %rax` |
| `x = a > b ? a : b` | `movq %rdi, %rax` / `cmpq %rdi, %rsi` / `cmovgq %rsi, %rax` |
| `x = abs(a)` | `movq %rdi, %rax` / `negq %rax` / `cmovsq %rdi, %rax` |

Counted loop over an `int[]` with an index:

```asm
    .text
    .globl  _count_greater
    .p2align 4
_count_greater:                      # long long count_greater(long long* a, long long n, long long t)
    xorl    %eax, %eax               # count = 0
    xorl    %ecx, %ecx               # i = 0
1:  cmpq    %rsi, %rcx               # while (i < n)
    jge     2f
    cmpq    %rdx, (%rdi,%rcx,8)      # compare a[i] with t
    jle     3f                       # skip unless a[i] > t
    incq    %rax
3:  incq    %rcx
    jmp     1b
2:  ret
```

Two pointers moving toward each other (in-place reverse, a `void` + mutates problem):

```asm
    .text
    .globl  _reverse
    .p2align 4
_reverse:                            # void reverse(long long* a, long long n)
    testq   %rsi, %rsi
    je      2f
    leaq    -8(%rdi,%rsi,8), %rsi    # rsi = &a[n-1]
1:  cmpq    %rsi, %rdi
    jae     2f                       # stop when the pointers meet (unsigned compare)
    movq    (%rdi), %rax
    movq    (%rsi), %rdx
    movq    %rdx, (%rdi)
    movq    %rax, (%rsi)
    addq    $8, %rdi
    subq    $8, %rsi
    jmp     1b
2:  ret
```

Max of a non-empty array with `cmov`:

```asm
    .text
    .globl  _max_of
    .p2align 4
_max_of:                             # long long max_of(long long* a, long long n), n >= 1
    movq    (%rdi), %rax             # best = a[0]
    movl    $1, %ecx                 # i = 1
1:  cmpq    %rsi, %rcx
    jge     2f
    movq    (%rdi,%rcx,8), %rdx
    cmpq    %rax, %rdx
    cmovgq  %rdx, %rax               # if (a[i] > best) best = a[i]
    incq    %rcx
    jmp     1b
2:  ret
```

## Stack frames & alignment

Needed when you call another function or use callee-saved registers. On entry `%rsp` is
8 mod 16; each `pushq` flips it. Before a `call` it must be a multiple of 16.

```asm
    .text
    .globl  _sum_sq
    .p2align 4
_square:                             # helper: rax = rdi * rdi
    movq    %rdi, %rax
    imulq   %rdi, %rax
    ret

_sum_sq:                             # long long sum_sq(long long* a, long long n)
    pushq   %rbp                     # rsp now 16-aligned
    movq    %rsp, %rbp               # frame pointer
    pushq   %rbx                     # save callee-saved registers we use
    pushq   %r12
    pushq   %r13
    subq    $8, %rsp                 # 3 pushes = 24 bytes: pad to a multiple of 16

    movq    %rdi, %rbx               # rbx = pointer   (survives call)
    movq    %rsi, %r12               # r12 = count
    xorl    %r13d, %r13d             # r13 = total
1:  testq   %r12, %r12
    je      2f
    movq    (%rbx), %rdi
    call    _square                  # clobbers rax rcx rdx rsi rdi r8-r11
    addq    %rax, %r13
    addq    $8, %rbx
    decq    %r12
    jmp     1b
2:  movq    %r13, %rax

    addq    $8, %rsp                 # undo the padding
    popq    %r13                     # restore in reverse order
    popq    %r12
    popq    %rbx
    popq    %rbp                     # (or `leaq -24(%rbp), %rsp` first if rsp moved)
    ret
```

With locals instead of pushes: `pushq %rbp; movq %rsp, %rbp; subq $32, %rsp`, use
`-8(%rbp)` … `-32(%rbp)`, and finish with `leave; ret` (`leave` = `movq %rbp, %rsp;
popq %rbp`). Keep the `subq` amount a multiple of 16.

## Bytes & strings

| task | instruction |
|---|---|
| load `s[i]` as unsigned | `movzbl (%rdi,%rcx), %eax` |
| load signed char | `movsbq (%rdi), %rax` |
| test for the terminator | `cmpb $0, (%rdi)` / `je done` (or `testb %al, %al`) |
| compare with a char | `cmpb $'a', %al` (or `cmpb $97, %al`) |
| store a byte | `movb %al, (%rsi)` / `movb $0, (%rsi)` |
| `c - '0'` | `subl $'0', %eax` (after `movzbl`) |

```asm
    .text
    .globl  _str_len
    .p2align 4
_str_len:                            # long long str_len(const char* rdi)
    movq    %rdi, %rax               # p = s
1:  cmpb    $0, (%rax)               # until the NUL terminator
    je      2f
    incq    %rax
    jmp     1b
2:  subq    %rdi, %rax               # p - s
    ret
```

```asm
    .text
    .globl  _count_char
    .p2align 4
_count_char:                         # long long count_char(const char* s, long long c)
    xorl    %eax, %eax
1:  movzbl  (%rdi), %ecx             # ecx = *s (zero-extended)
    testl   %ecx, %ecx
    je      2f
    cmpb    %sil, %cl                # compare low bytes
    jne     3f
    incq    %rax
3:  incq    %rdi
    jmp     1b
2:  ret
```

## C ↔ assembly cheat table

| C | x86-64 (AT&T) |
|---|---|
| `x = a + b * 4` | `leaq (%rdi,%rsi,4), %rax` |
| `x = a * 10` | `imulq $10, %rdi, %rax` |
| `if (a < b) goto L` | `cmpq %rsi, %rdi` / `jl L` |
| `if (n == 0) goto L` | `testq %rsi, %rsi` / `je L` |
| `x = (a == b)` | `xorl %eax, %eax` / `cmpq %rsi, %rdi` / `sete %al` |
| `x = a < b ? a : b` | `movq %rdi, %rax` / `cmpq %rdi, %rsi` / `cmovlq %rsi, %rax` |
| `p[i]` (8-byte) | `movq (%rdi,%rcx,8), %rax` |
| `p[i] = x` | `movq %rax, (%rdi,%rcx,8)` |
| `*p++` | `movq (%rdi), %rax` / `addq $8, %rdi` |
| `s[i]` (char) | `movzbl (%rdi,%rcx), %eax` |
| `a / b`, `a % b` | `movq %rdi, %rax` / `cqto` / `idivq %rsi` → `%rax`, `%rdx` |
| `a / 2` (signed, C semantics) | `idivq`, or `sarq $1` only when `a >= 0` |
| `a % 2 != 0` | `testq $1, %rdi` / `jne L` |
| `return x` | `movq x, %rax` / `ret` |

## Common errors

| message | cause |
|---|---|
| `Undefined symbols for architecture x86_64: "_f"` | missing `.globl _f`, label lacks the underscore, or a typo in the name |
| `invalid operand for instruction` | wrong operand kind/size: a >32-bit immediate in `addq`/`cmpq`/a store, `cmovlq $1, %rax`, `movq %eax, %rbx`, memory-to-memory move |
| `too few operands for instruction` | e.g. `imulq $3` (the immediate form needs a destination) |
| `invalid instruction mnemonic 'cmovq'` | `cmov` needs a condition: `cmovlq`, `cmoveq`, … |
| `unknown use of instruction mnemonic without a size suffix` | Intel syntax (`mov rax, rdi`) in AT&T mode |
| `ambiguous instructions require an explicit suffix` | `mov $1, (%rdi)`: no register fixes the size; write `movq` |
| `32-bit absolute addressing is not supported in 64-bit mode` | `movq table, %rax` (use `table(%rip)`), or a register missing its `%` (`movq rdi, %rax`) |
| `unexpected token in '.section' directive` | ELF section names (`.rodata`); use `.section __TEXT,__const` |

| crash | likely cause |
|---|---|
| `Segmentation fault: 11` / `Bus error: 10` | bad pointer, `ret` with `%rsp` unbalanced (missing `pop`, leftover `subq`), `movq 5, %rax` (forgot `$`), index not scaled by 8 |
| crash inside a libc call (`movaps` fault) | `%rsp` not 16-byte aligned at the `call` |
| `Illegal instruction: 4` | `shlq %rcx, %rax`: clang encodes it as a newer (APX) instruction; write `shlq %cl, %rax` |
| `Floating point exception: 8` | `idiv`/`div` by zero, `INT64_MIN / -1`, or forgot `cqto` / `xorl %edx, %edx` so the quotient overflows |
| wrong result after a `call` | value kept in a caller-saved register (`%rax %rcx %rdx %rsi %rdi %r8`–`%r11`) |
| wrong result from a byte load | `movb` into `%al` left junk in the upper bits; use `movzbl` |

## Common gotchas

- **Operand order**: `subq %rsi, %rax` is `rax -= rsi`; `cmpq %rsi, %rdi; jl` is `rdi < rsi`.
- Forgetting `$` on an immediate turns it into a memory load.
- The symbol must be `_fn`, exported with `.globl _fn`.
- Array elements are 8 bytes: scale indices by 8 (`(%rdi,%rcx,8)`) or advance by 8.
- `idivq` needs `cqto` first and destroys `%rdx` (argument 3).
- `xorl %eax, %eax` clobbers flags: put it **before** the `cmp`, not between `cmp` and `setcc`.
- `setcc` writes only one byte: zero the register beforehand or `movzbl` afterwards.
- `l`/`g` are signed, `b`/`a` unsigned.
- `inc`/`dec` don't update CF, so `jb`/`jae` after them test a stale carry.
- Variable shift counts must be in `%cl` (`%rcx` assembles but crashes).
- `cmov` can't take an immediate source; load the constant into a register first.
- `%rsp` must be 16-aligned at `call` and back to its entry value at `ret`.
